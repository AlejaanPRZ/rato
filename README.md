# RATO

Web de la marca **RATO** con la colección de lanzamiento *Bajamos un momento*.

Sitio estático: una sola página, sin dependencias ni build.

```
index.html   · la página completa (CSS y SVG en línea)
img/         · vistas de diseño de las 5 camisetas (.webp)
```

## Ver en local

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Publicar con GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → rama `main`, carpeta `/ (root)`.
